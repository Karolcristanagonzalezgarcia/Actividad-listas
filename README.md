# Actividad-listas

Programas de Manipulación de Listas en Python

Este repositorio reúne cuatro programas desarrollados en Python como parte de las prácticas de programación del primer semestre de la universidad. Cada ejercicio tiene como objetivo fortalecer el uso de listas, ciclos, funciones y estructuras condicionales mediante la resolución de problemas básicos de procesamiento de datos.

Los programas incluidos son:

- Contador de números pares e impares: recibe una lista de números enteros y determina cuántos son pares y cuántos son impares.
- Suma de una lista: calcula la suma de los elementos de una lista utilizando tanto un algoritmo con ciclos como la función integrada "sum()", permitiendo comparar ambos métodos.
- Máximo y mínimo manual: identifica el valor mayor y el valor menor de una lista implementando un algoritmo propio, sin depender de las funciones integradas de Python.
- Inversión manual de una lista: genera una nueva lista con los elementos en orden inverso mediante un recorrido manual de los índices.

Este repositorio refleja la aplicación de conceptos fundamentales de programación, incluyendo el manejo de listas, funciones, estructuras de control y el desarrollo de algoritmos para la resolución de problemas básicos en Python.
